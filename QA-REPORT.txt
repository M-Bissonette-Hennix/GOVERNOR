BROWSER QA LIMITATION
---------------------
The available system Chromium is governed by an administrator policy that blocks local/file navigation (`ERR_BLOCKED_BY_ADMINISTRATOR`). A separate Playwright browser binary was not installed and the environment could not download it because external package DNS/download access was unavailable. Therefore an automated rendered-page test could not be completed inside this build environment.

This is why `ACCEPTANCE-TESTS.md` remains part of commissioning: the final authority is the actual GitHub Pages URL installed on the target iPhone. No claim is made that an unexecuted device/browser acceptance test has passed.
